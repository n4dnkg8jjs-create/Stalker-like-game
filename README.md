# Zone 12

A first-person, STALKER-inspired browser game: a Russian CBRN soldier in the Ratnik kit, a forward operating base, a BTR-80 ride to Sector 1 and an abandoned farmhouse.

Play: open `index.html` in a modern desktop browser (Chrome, Edge or Firefox). Internet access is needed for the 3D library and fonts.

Controls: WASD move, Shift sprint, C crouch, mouse look/fire, right mouse aim, R reload, E interact, Tab inventory, F flashlight.

Character bodies are built from the CC0 MakeHuman base mesh, targets, skeleton and eye assets (makehumancommunity.org).
